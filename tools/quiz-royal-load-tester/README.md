# 퀴즈 로얄 — 다중 클라이언트 통합 시험

교사 1 + 길드 태블릿(대표 계정) N대를 실제 Supabase에 동시에 붙여 퀴즈 한 판을 자동으로 돌립니다.
**B.R.A.N.D LOADTEST 학급 교사 계정으로만 실행됩니다.** 리허설 대회를 만들고 끝나면 지웁니다.

## 준비 (한 번만)
1. `supabase/APPLY_QUIZ_ROYAL_V1.sql` 을 먼저 적용합니다.
2. LOADTEST 학급에는 지금 길드가 없습니다. 교사 패널(LOADTEST 교사로 로그인) → 길드 관리에서
   **길드 5개를 만들고 LOADTEST 학생을 나눠 배정**합니다(4~5명씩).
3. 학생 비밀번호 CSV: `QUIZ_LOAD_TEST_CREDENTIALS.csv` (없으면 도구함 부하 시험 CSV를 그대로 씁니다).
   형식은 `.sample.csv` 참고. 이 파일은 Git에 올라가지 않습니다.

## 실행
프로젝트 폴더(C:\brand_2.0\brand_2.0)에서:
```
node tools/quiz-royal-load-tester/run.mjs
```
교사 이메일·비밀번호를 물어봅니다. 결과는 `tools/quiz-royal-load-tester/results/REPORT.txt`.

## 확인하는 것
- 학생 계정의 문제·답안 표 직접 읽기 거절
- 문제 시작 신호가 태블릿 전원에 2초 안에 도착
- 대표마다 3번 연타해도 길드당 답 1건, 모두 내면 자동 마감
- 일시정지 중 제출 거절, 재개 뒤 남은 시간 유지
- 시간+유예(1초) 지난 제출 거절
- 중계 화면 응답에 정답·미공개 답안이 섞이지 않음(단계마다)
- 채점 확정 동시 3번 → 점수 1번만
- 개인전 발표 → 단체전 → 최종 발표 → 종료, 운영 이력
