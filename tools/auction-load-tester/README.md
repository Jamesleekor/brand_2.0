# B.R.A.N.D 2.0 실시간 경매 부하 테스트 (AUCTION_LOAD_TEST_V1)

선생님 운영 화면 1개 + 학생 24명이 동시에 경매에 참여해 **즉시 입찰 버튼을 연타**하는 상황을 재현합니다.

- 실행: 프로젝트 루트의 `RUN_AUCTION_LOAD_TESTER.cmd`
- 테스트 전용 학급 `B.R.A.N.D LOADTEST`(classroom #5, 2026-10-01 생성)에서만 동작합니다.
  다른 학급 계정이면 시작 전에 멈춥니다. 실제 5-4반 데이터는 건드리지 않습니다.
- 학생 동작은 앱과 같습니다: 2.5~3초 주기 상태 조회, 입찰은 한 번에 1건, 성공 시 즉시 재조회,
  "연결 지연" 상태·최고 입찰자·잔액 부족이면 버튼 비활성, 낙찰 예비 처리 25~40초 후 최대 2회.
- 선생님 동작: 1.5~2초 주기 조회, 마감 즉시 SUPER PASS 마감/낙찰 처리, 3초 뒤 다음 상품 시작.
- 매 실행마다 같은 테스트 회차(1회차)를 초기화하므로 이전 낙찰금은 자동으로 되돌려집니다.
- Ctrl+C: 진행 중 상품을 정리하고 결과를 저장한 뒤 종료합니다.
- 결과: `tools/auction-load-tester/results/*_REPORT.txt` → Claude에게 붙여넣기.
- 같은 서버를 사용하므로 **수업 중에는 실행하지 마세요.**

계정 파일 `AUCTION_LOAD_TEST_ACCOUNTS.json`은 테스트 전용 계정이며 Git에 올라가지 않습니다(.gitignore).
