# B.R.A.N.D 2.0 아케이드 공인 도전 부하 테스트 (ARCADE_VERIFY_LOAD_TEST_V1)

선생님 1 + 학생 24명이 순수 반응속도(pure_reaction_02) **공인 도전**을 동시에 진행하는 상황을 재현합니다.

- 실행: 프로젝트 루트의 `RUN_ARCADE_LOAD_TESTER.cmd`
- 테스트 전용 학급 `B.R.A.N.D LOADTEST`(classroom #5)에서만 동작합니다. 계정은 경매 테스트와 같은
  `tools/auction-load-tester/AUCTION_LOAD_TEST_ACCOUNTS.json`을 사용합니다.
- 실행할 때마다 테스트 학급에 "LOADTEST 공인도전 …" 월간 기간을 새로 만들고 인증 단계로 전환합니다.
  실제 5-4반 기록·랭킹·길드 점수에는 영향이 없습니다.
- 학생 동작: 앱 접속(로그인 확인·접속 기록·상호평가 확인·아케이드 화면 데이터) → 선생님이 열어줄 때까지 대기
  → 공인 도전 시작 → 카운트다운 → 실제 시간대로 5회 반응 → 제출 → 랭킹·상태 갱신. 실패 시 남은 기회로 재도전.
- 기다리는 방식: 1=새로고침(F5) 반복(10~25초마다 앱 전체 다시 열기), 2=조용히 대기(15초마다 상태만 확인).
  두 방식을 모두 돌려 비교하면 "새로고침 폭주"가 얼마나 부담인지 알 수 있습니다.
- 앱의 브라우저 요청 제한(일반 요청 동시 2개·대기 8초·시간 초과 12/15초)을 그대로 따릅니다.
- 부정 출발을 5% 섞어 재도전 흐름도 확인합니다.
- 결과: `tools/arcade-load-tester/results/*_REPORT.txt` → Claude에게 붙여넣기.
- 같은 서버를 사용하므로 **수업 중에는 실행하지 마세요.** 1회 실행에 약 2~3분 걸립니다.
