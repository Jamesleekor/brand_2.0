# 소통 운영 UI 개선 — 2026-10-19

기준: main 66c5920. 프론트엔드 수정본이며 GitHub 반영·배포는 미실시.

## 변경

- 우편 발송을 전체 폭으로 확장. 넓은 화면에서는 왼쪽 수신자 목록 / 오른쪽 작성 영역, 좁은 화면에서는 세로 배치.
- 본문 최소 높이 360px, 1280px 이상 화면에서는 420px. 수동 세로 크기 조절, 5,000자 카운터, 선택형 수신 화면 미리보기.
- 학급 전체 알림을 별도 접이식 패널로 이동. 기본 접힘이며 접었다 펼쳐도 입력값 유지.
- 우편의 http://, https://, www. 주소를 새 탭 링크로 표시. 교사 발송 상세 / 학생 소식함 / 기존 우편함 모달 / 작성 미리보기 적용.
- 기존 메시지도 다시 열면 URL 링크 적용. 저장 내용·RPC·DB·실시간 처리 변경 없음.
- HTML은 텍스트로 표시. HTTP(S) 외 스킴은 링크로 실행하지 않음. 문장 끝 기호와 URL 밖 괄호 분리.
- 발송 이력 표에 열 너비 고정, 관리 열 164px 확보. 상세·회수 버튼은 줄바꿈·축소 방지, 안쪽 여백 축소. 좁은 화면에서는 표 안에서 가로 스크롤.

## 검증 상태

- 변경 TS/TSX 5개 TypeScript 5.6.3 transpileModule 구문 검사 통과.
- URL 처리 14개 사례 통과: HTTP(S), www, 여러 링크·줄바꿈, 문장부호, URL 내부/외부 괄호, 한글 도메인, 잘못된 URL, 이메일 일부, HTML·실행 스킴, 긴 주소, 원문 복원.
- 저장소 AGENTS.md 규칙에 따라 npm 설치·빌드·dev 실행 안 함. 전체 프로젝트 타입 검사와 로그인 E2E는 미실시.

## 사용자 확인

1. 적용 후 로컬에서 `npm run build` 실행.
2. 교사 소통: 수신자 선택/전체 선택/초기화, 긴 본문 편집·세로 크기 조절, 글자 수, 미리보기의 링크 클릭 확인.
3. 학급 알림은 기본 접힘. 펼친 뒤 작성 → 접기 → 펼치기 시 내용 유지 및 기존 발송 확인.
4. 테스트 계정으로 링크 포함 우편을 발송하고, 교사 발송 상세 / 학생 소식함 / 기존 우편함에서 새 탭 연결 확인.
5. 과거 우편의 URL과 읽음 수·회수 동작 확인.
6. 1920/1366/1024/390px 화면에서 작성 영역과 상세·회수 버튼 확인. 작은 화면에서 표만 가로 스크롤되는지 확인.
