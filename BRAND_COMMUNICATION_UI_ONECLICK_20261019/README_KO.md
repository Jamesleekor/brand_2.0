# B.R.A.N.D 소통 UI 수정본

1. ZIP을 압축 해제하고 생긴 폴더를 `package.json`이 있는 프로젝트 폴더 안에 넣으세요.
2. `APPLY.cmd`를 실행하세요. Node.js만 사용하며 추가 패키지를 설치하지 않습니다.
3. 적용 완료 후 프로젝트 폴더에서 `npm run build`로 확인하세요.

우편 작성 확대, 학급 알림 접이식 전환, URL 자동 링크, 상세·회수 버튼 한 줄 배치를 포함합니다. 링크는 교사 상세·학생 소식함·기존 우편함에서 새 탭으로 열립니다.

모든 대상 파일을 먼저 검사하고 원본을 백업한 뒤 적용합니다. 현재 소스가 기준과 다르면 아무 파일도 덮어쓰지 않고 중단합니다. CRLF/LF 차이는 허용하며 같은 패치는 재실행해도 중복 적용하지 않습니다. 실패하면 표시된 오류를 전달해주세요.

자동 설치·빌드·커밋·push·DB 변경은 없습니다. 검증 범위와 로그인 확인 항목은 `payload/docs/COMMUNICATION_UI_2026-10-19.md`에 있습니다.
