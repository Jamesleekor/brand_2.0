# 원정 상자 개봉 연출 (2026-10-17)

## 학생 경험

상자 열기 클릭 즉시 전용 창을 표시한다.
봉인 해제(상자 흔들림·빛·회전 고리) → 개봉 빛 → 보상 공개 순서다.

| 상자 | 봉인 해제 | 개봉 빛 | 기본 총 시간 | 색상 |
| --- | ---: | ---: | ---: | --- |
| 일반 | 900ms | 420ms | 1.32초 | 금빛 |
| 중급 | 1200ms | 520ms | 1.72초 | 청록빛 |
| 희귀 | 1450ms | 650ms | 2.10초 | 보랏빛 |

보상이 확정되면 연출을 건너뛸 수 있다.
움직임 줄이기를 선택한 기기에서는 서버 응답 후 즉시 보상을 표시한다.
등장 연출은 상자 등급에 따라 달라지며 개별 상품의 드롭 확률을 희귀도로 해석하지 않는다.
효과음은 추가하지 않는다.

폰트·배경/CG는 획득한 상품 정보를 조회해 실제 미리보기를 표시한다.
조회·이미지 로딩 실패 시 기본 보상 상징과 결과 이름으로 확인할 수 있다.

## 보상 처리

- 기존 student_open_expedition_box RPC와 요청 식별자를 그대로 사용한다.
- 개봉 중 참조 잠금과 버튼 비활성화로 중복 클릭을 차단한다.
- 보상 추첨·상자 차감·자산 지급 시점과 확률은 바꾸지 않는다.
- 연출은 서버 결과를 받은 뒤 공개한다. 응답이 느리면 대기 상태를 유지한다.
- 건너뛰기·확인·닫기는 추가 RPC를 호출하지 않는다.
- 개봉 결과 문구와 상자함의 최근 보상은 연출 창을 닫은 뒤 갱신한다.
- 서버 오류는 창 안에 표시하고 상자함 수량을 다시 조회한다.

## 접근성·레이아웃

dialog/aria-modal, 상태 알림, 키보드 포커스 유지·복원, 배경 스크롤 잠금을 적용한다.
Escape는 결과가 확정된 개봉 연출을 건너뛰고, 공개 완료·오류 상태에서는 창을 닫는다.
작은 화면은 창 내부에서 스크롤하며 텍스트가 긴 보상 이름도 줄바꿈한다.
모든 CSS 애니메이션은 해당 개봉 창 클래스에 한정한다.

## 검증

`node --experimental-strip-types tests/expedition_chest_opening.mjs` 통과:
일반·중급·희귀 타이밍, 빠른/느린 서버 응답, 결과 확정 전 공개 금지,
움직임 줄이기, 공개 후 단계 유지.

AI가 npm 설치·production build를 실행하지 않는 저장소 운영 규칙을 준수했다.
이 환경에는 실행 가능한 브라우저가 없어 화면 실물 검증은 수행하지 못했다.
사용자 환경에서 일반·중급·희귀 개봉, 건너뛰기, 폰트·CG 미리보기,
작은 화면·키보드·네트워크 오류 처리를 확인한다.
