# A클래스 특별 히든 편린 이미지

## 요청 및 상품

| 상품 | 원본 보유 조건 | 가격 | 전시 이미지 |
|---|---|---|---|
| 아스텔(아스트라의 축복) | CHAR-022 아스텔 | 250 CRYSTAL | CHAR-022-Astell-Prestige.webp |
| 루미(행복한 순간) | CHAR-012 루미 | 250 CRYSTAL | CHAR-012-Rumi-Prestige.webp |

별도 편린을 영입하는 상품이 아니라 기존 편린의 추가 전시 이미지 이용권이다.
보유 편린 수, 콜렉션 진행률, 공명력, 치명타율을 변경하지 않는다.
두 캐릭터의 현재 비어 있는 `showcase_image_url_2`를 사용한다. 기존 기본 이미지와 신뢰 보상/CG는 보존한다.

## 구현

- 상품 category: `character_visual`, presentation_kind: `HIDDEN_SHARD_IMAGE`, A / level 1.
- 상품 UID: `HIDDEN_ASTELL_PRESTIGE_2026`, `HIDDEN_RUMI_PRESTIGE_2026`.
- 카탈로그 metadata에 `required_character_uid`, `visual_variant_no: 2`를 연결한다.
- 기존 명품관 개방 효과와 판매 기간을 따른다. 임의 체험 개방을 추가하지 않는다.
- 구매 하위 함수 `purchase_cosmetic_item`에서 원본 보유를 확인하므로 가격을 운영 UI에서 바꿔도 조건이 유지된다.
- 전시 저장/해금 조회/홈 조회가 공통 권한 판정을 사용한다. 미구매 특별 이미지 저장은 거부한다.
- 상품 회수 후 저장된 전시 번호가 남아 있어도 홈 응답은 기본 이미지로 처리한다.
- 원본 편린이 없는 학생에게 운영국이 이미지 이용권을 지급한 경우, 원본을 획득한 뒤 전시할 수 있다.
- 소장한 상품이 판매 종료되어도 전시 권한은 유지된다.
- 다른 편린의 기존 신뢰 보상 해금 규칙은 유지한다.
- 구매 성공 후 편린 컬렉션과 홈 꾸미기 캐시를 무효화한다.
- A클래스는 2열 이미지 카드, 보유 조건·가격·소장 상태를 표시한다. 홈 이미지 선택에는 상품명과 명품관 해금 안내를 표시한다.

두 이미지 URL은 HTTP 200 및 WebP 파일로 확인했다.
**운영 DB migration 요청이 승인 단계에서 거절되어 적용되지 않았다. 구체 거절 사유는 반환되지 않았다.**
읽기 전용 재확인에서 새 상품은 0개다. 커밋·푸시, npm 설치·빌드, 로그인 E2E는 실행하지 않았다.
조회 시점에 활성 COSMETIC 명품관 개방 효과도 0개였다. 상품 등록과 별개로 기존 개방 기간 규칙을 따르며, 다음 개방 시 기존 동기화 함수가 A클래스 판매 기간을 설정한다.
원클릭 패치 검증: 기준 소스 9개 파일 결과 일치, 재실행, 관련 없는 수정 및 CRLF 보존, 충돌 시 전체 무변경, CMD ASCII/CRLF 검사 통과.

SQL 준비본: `supabase/APPLY_A_CLASS_HIDDEN_VISUALS_20261014.sql`.
운영 DB 적용에는 재승인이 필요하며, 파일은 동일 SQL 재검토를 위한 전달본이다. CMD는 DB SQL을 실행하지 않는다.
DB 적용 후 사용자 환경에서 프론트 패치와 빌드를 진행한다.
DB 함수가 그사이에 바뀌면 preflight가 중단하므로 최신 정의를 다시 비교한다.

## E2E 확인 항목

1. 원본 미보유 학생: 구매 불가 안내 / RPC 직접 구매 시에도 거부 / 크리스탈 미차감.
2. 원본 보유·특별 이미지 미보유: 기본 이미지는 선택 가능, 특별 이미지는 잠금.
3. 구매: 선택한 상품만 등록, 정확히 250크리스탈 차감, 중복 구매 실패 시 추가 차감 없음.
4. 구매 직후 홈 꾸미기 → 편린 전시 → 해당 편린 → 기본/특별 이미지 선택 → 저장·새로고침 유지.
5. 다른 학생의 상품 보유로 자기 이미지가 해금되지 않음.
6. 운영국 지급 후 원본 보유자는 전시 가능. 회수 후 특별 이미지는 다시 잠기고 홈에서 기본 이미지 사용.
7. 원본 미보유자에게 이미지 이용권을 지급해도 전시 불가. 원본 획득 후 가능.
8. 다른 편린의 기존 이미지 2/3 및 신뢰 잠금은 기존과 동일.
9. A/B/C 클래스, 운영국 상품 가격 변경·학생별 지급, 명품관 개방/종료 동작 확인.
