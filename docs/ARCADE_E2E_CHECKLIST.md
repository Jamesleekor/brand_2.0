## 교사: 기간과 운영

- `/teacher/arcade`에서 월간 기간을 만들면 처음에는 `초안`으로 표시된다.
- 길드 시즌을 선택한 경우, 다른 학급의 시즌은 선택/저장할 수 없다.
- `기간 열기` 후 학생 `/arcade`에서 해당 기간을 선택할 수 있다.
- 종료 시각이 지나기 전에는 `월간 순위 확정 + Guild 2 반영` 버튼이 비활성이다.
- `ACTIVE` 기간의 `⏹ 랭킹 기간 즉시 종료`를 누르면 서버 시각으로 즉시 종료되고, 새 기록 접수가 멈춘 뒤 `월간 순위 확정 + Guild 2 반영` 버튼이 활성화된다.
- 종료 뒤 확정하면 `확정` 상태가 되고, 같은 기간을 다시 일반 수정/재확정할 수 없다.
- 확정 결과 뒤 `/teacher/guild/scores`에서 학생별 `원점수`, `반영 +N / 90`, `최종 / 990`을 확인한다.
- 공개일 전 `/teacher/arcade`의 `사전 테스트 허용`에서 학생을 선택해 허용할 수 있고, 해제도 할 수 있다.

## 학생: Game #01

- `/arcade`에 `집중 반응 #01`과 기간별 Top 10이 보인다.
- 한국 날짜가 `available_from` 이전이면 시작 버튼이 비활성이고, 서버도 시작 요청을 거절한다.
- 시작 버튼 뒤 5초 준비 시간이 보이며, D/F/J/K 또는 화면의 네 버튼으로 조작한다.
- 파란 신호는 같은 레인 키, 빨간 `✕`는 누르지 않는다.
- 잘못 누르기·GO 놓치기·NO-GO 누르기가 Life를 줄이고 600ms 회복 표시가 보인다.
- Life 3개가 모두 사라지면 자동으로 제출되고, 화면에 **서버가 계산한 공식 점수**가 보인다.
- 브라우저 개발자도구에서 점수 값을 바꾸려 해도 저장 요청에는 점수 field가 없으며, 순위는 바뀌지 않는다.
- 탭을 다른 곳으로 전환했다 돌아오면 게임 시간이 멈추지 않고 경과한 만큼 진행된다.
- 공개일 전 사전 테스트가 허용된 학생은 `사전 테스트 시작` 버튼으로 실제 서버 검증 게임을 플레이할 수 있다.
- 사전 테스트 결과에는 `순위·월간 확정·Guild 2 점수에 반영되지 않는다`는 안내가 보인다.
- 사전 테스트 시작부터 종료·저장까지 `42883` 또는 함수 탐색 오류 없이 완료된다.
- 파란 신호를 올바른 타이밍에 누르면 화면 중앙에 `PERFECT`·`GREAT`·`GOOD` 판정, 획득 점수, 현재 콤보가 보이고 해당 레인이 짧게 반응한다.
- 놓치거나 잘못 누르면 `MISS`·`NO GO`·`WRONG KEY`와 `LIFE -1`이 크게 보이며, 하트와 해당 레인이 붉게 반응하고 회복 중 안내가 표시된다.
- 신호가 판정선에 닿기 전에 너무 일찍 누르면 Life를 잃고 다음 신호로 진행한다. 이 입력으로 Life가 모두 사라진 경우에도 결과가 `GAME_NOT_OVER`로 거절되면 안 된다.
- 빨간 `✕` 신호를 누르지 않고 정상 통과한 뒤에도 다음 신호가 계속 진행되어야 한다. 이후 Life 3개가 소진된 run이 `GAME_NOT_OVER`로 거절되면 안 된다.
- Life가 0이 된 뒤 게임 화면이 바로 사라지지 않고, 서버 검증 뒤 같은 화면에서 공식 점수·플레이 시간·최대 콤보·성공 입력·현재 순위를 확인할 수 있다. 사전 테스트는 순위 대신 제외 안내를 보여야 한다.
- 사전 테스트 결과의 `서버 인정 입력`이 화면에서 표시한 성공 판정 수와 다르면, 0점으로 넘기지 않고 검증 차이 안내가 표시되어야 한다.

## 랭킹과 Guild 2

- 한 학생이 여러 번 플레이해도 한 기간 Top 10에는 최고점 1개만 들어간다.
- 동점은 `공식 점수 내림차순 → game_over_at 오름차순 → run_id 오름차순`이다.
- 1위/2위/3위/4~6위/7~10위 보너스가 각각 `30/27/24/18/15`이다.
- 여러 게임의 원본 합계가 +90을 넘어도 `arcade_raw_total`은 보존되고 `arcade_applied`는 최대 +90, `final_total`은 최대 990이다.
- 월간 확정 뒤 새 run 또는 무효 처리 이후에도 **확정 월간 Top 10은 기존 snapshot과 동일하게 유지**된다.
- 확정 월간에서 Top 10 밖 테스트 학생으로 로그인해도 그 학생의 최종 `내 순위`와 `내 최고점`이 immutable full-rank snapshot 값으로 표시된다.
- 확정 상태인데 period/game snapshot이 없는 비정상 데이터는 빈 순위표가 아니라 이해 가능한 오류 안내로 표시된다.
- 교사 감사 기록에서 `REJECTED`이며 `game_over_at`이 없는 기록도 보이고, rejection code/reason이 표시된다.
- 사전 테스트 run은 교사 감사 기록에 `사전 테스트`로 보이지만, ACTIVE leaderboard·월간 Top 10·full-rank snapshot·Guild 2에는 포함되지 않는다.
- 교사 `/teacher/arcade`의 `사전 테스트 순위 보기`에서는 사전 테스트 학생만, 학생당 최고 서버 점수 하나로 표시된다. 점수 내림차순 → 먼저 게임 종료 → run ID 순서가 동점 규칙과 일치해야 하며, 이 표는 공개 순위에 나타나면 안 된다.

## 권한과 오류 안내

- 학생은 `/teacher/arcade`로 직접 들어갈 수 없다.
- 학생은 다른 학생의 run/result/raw input/audit를 볼 수 없다.
- 교사만 기간 생성·활성화·월간 확정·무효 처리를 할 수 있다.
- 입력 형식 또는 네트워크 오류가 나면 버튼이 멈춘 것처럼 보이지 않고 화면에 한국어 안내가 보인다.
