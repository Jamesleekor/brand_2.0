# 프로필 스페셜 편린 이미지 선택

적용일: 2026-11-02

## 목적

명품관에서 구매하거나 차원관문 보상으로 해금한 편린 이미지를 홈 전시뿐 아니라 공개 프로필의 대표 이미지로 선택할 수 있게 한다.

## 동작

- 편린 도감의 보유 편린 상세 화면에 `프로필 대표 이미지` 선택관이 표시된다.
- 기본 이미지와 등록된 스페셜 이미지를 함께 보여준다.
- 미해금 이미지는 미리보기와 잠금 사유를 표시하되 선택할 수 없다.
- 선택 저장은 `student_equip_character_visual(bigint, integer)` RPC에서 편린 보유와 이미지 해금 권한을 다시 검증한다.
- 선택 결과는 친구/랭킹, 길드, 홈 상단 프로필 등 `useEquippedCharacters` 공통 어댑터를 쓰는 공개 화면에 반영된다.
- 레이드에서 기존 `equip_character(bigint)`를 호출해 같은 편린을 다시 선택해도 스페셜 이미지 선택은 유지된다. 다른 편린으로 바꾸면 기본 이미지로 초기화된다.

## 데이터

- `student_character_profiles.visual_variant_no`: `1` 기본, `2`/`3` 스페셜 이미지
- 기존 27개 프로필 행은 모두 `1`로 안전하게 유지했다.
- 명품관 구매 권한은 기존 `_character_showcase_visual_allowed`를 재사용한다.

## 신규 상품 연결 규칙

새 스페셜 편린 상품은 기존 A클래스와 동일하게 다음 세 항목을 연결하면 별도 프론트 수정 없이 자동 노출된다.

1. `characters.showcase_image_url_2` 또는 `showcase_image_url_3`
2. `expedition_luxury_catalog.presentation_kind = 'HIDDEN_SHARD_IMAGE'`
3. 카탈로그 `metadata`의 `required_character_uid`, `visual_variant_no`

## 학생 E2E 체크

1. 스페셜 이미지를 구매하지 않은 편린에서 잠금 카드가 선택 불가인지 확인한다.
2. 구매한 아스텔/루미/로벨리아에서 기본·스페셜 이미지가 모두 선택 가능한지 확인한다.
3. 스페셜 이미지로 장착 후 친구/랭킹, 길드, 홈 상단 프로필에 같은 이미지가 표시되는지 확인한다.
4. 같은 편린을 레이드에서 다시 선택해도 스페셜 이미지가 유지되는지 확인한다.
5. 다른 편린으로 변경하면 기본 이미지로 시작하는지 확인한다.
6. 장착 해제 시 공개 프로필 이미지가 제거되는지 확인한다.

## 후속 등록 대기

네빌(`CHAR-081`), 알렉(`CHAR-058`), 루시페라(`CHAR-077`), 나르타스(`CHAR-078`), 라피네아(`CHAR-079`)는 스페셜 이미지 URL과 상품명이 확정되면 A클래스 카탈로그에 등록한다.
