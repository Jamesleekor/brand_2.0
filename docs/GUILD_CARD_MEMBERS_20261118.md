# 길드 현황 카드 구성원 표시 (2026-11-18)

- 대상: 교사 운영 패널 → 길드&콘텐츠 → 길드 현황.
- 각 카드에 학생 실명과 담당 속성을 함께 표시한다. 브랜드명은 마우스 오버로 확인한다.
- 실명이 없으면 브랜드명, 둘 다 없으면 학생 번호를 표시한다.
- 이름은 줄바꿈하고, 빈 길드는 ‘소속 길드원 없음’으로 표시한다.
- 기존 studentById와 활성 membership 목록을 재사용한다. 현재 화면의 인원 집계와 동일한 구성원이다.
- 길드 배정/이동/해제 후 기존 guild1-admin 캐시 갱신을 통해 이름도 갱신된다.
- 조회/RPC/DB schema/과거 소속 이력 변경 없음.
- GitHub main c20829465f840424d7a53d583aea842c0016463b 기준 부분 패치.

## 적용

BRAND_GUILD_CARD_MEMBERS_20261118.cmd를 실행한다.
대상 루트: C:\brand_2.0\brand_2.0
변경 전 파일은 _brand_patch_backups 아래에 보관한다.
원본 블록이 일치하지 않으면 파일을 변경하지 않고 중단한다.
반복 실행 시 이미 반영된 수정은 건너뛴다.
스크립트는 npm 설치/빌드, commit/push, DB 작업을 실행하지 않는다.

## 확인

AI: 소스 diff, 조회 변경 여부, 치환 일치/반복 실행/불일치 중단 검증.
사용자 로컬 빌드와 로그인 화면 검증은 미완료.

1. npm run build 실행.
2. 교사 길드 현황에서 인원수와 이름 배지 수가 같은지 확인.
3. 4명/5명 길드, 빈 테스트 길드, 담당 속성 미설정 확인.
4. 좁은 화면에서도 이름이 잘리지 않고 줄바꿈하는지 확인.
5. 한 학생 이동 후 이전/새 길드 카드의 이름과 인원이 함께 갱신되는지 확인.
