# 원정 보상 수령 시점

일반 학생은 토요일 원정 보상을 해당 주 일요일 시작(sun_open_at), 일요일 원정 보상을 일요일 종료(sun_close_at, 월요일 0시)부터 수령한다. DB 학생 레코드의 is_test_account=true만 대기 예외다. 출발 즉시 보상 추첨 결과는 확정하되 자산 지급은 수령 RPC가 다음 날까지 차단한다. 기존 수령 기록은 멱등 응답으로 유지한다.

화면은 서버의 can_claim_now와 claim_available_at으로 대기 상태와 한국 시간을 표시한다. 오래된 클라이언트도 서버 검사로 조기 수령할 수 없다. 미수령 보상의 기존 주간 자동정산(월요일 00:05)은 유지한다.

검증: 실제 함수 정의로 만든 임시 함수에 테스트요원 원정의 복제 fixture를 사용해 일반 학생 조기 수령 차단과 테스트 계정 예외를 검증한다. 운영 자산/이력은 변경하지 않는다. 실제 브라우저 확인 및 로컬 production build는 별도 필요하다.
