# 2026년 10월 MVP · 로그인/기록실 반영

## 반영 상태

- 운영 DB: `records_october2026_mvp_and_hall_update` 증분 migration 적용 완료.
- 소스: 로컬 수정 및 정적 검증 완료. GitHub commit/push, 사용자 로컬 build, 배포 후 로그인 화면 E2E는 대기.
- AI는 `npm ci`, `npm install`, `npm run build`, `npm run dev`를 실행하지 않는다. 실제 설치와 production build는 사용자가 자신의 PC에서 실행한다(AGENTS.md §8.1).

## 변경

- 로그인: 승인된 10월 이준혁 초상화를 우측 퍼레이드에 추가. 모바일 하단 퍼레이드에도 포함.
- 3·4·5·7월 로그인 초상화를 지정된 All-Time-MVP-Winners 파일로 교체. 동일 경로의 브라우저 캐시를 피하도록 새 버전 쿼리 사용. 6·9월은 유지.
- 2026년 10월 아카이브: 이준혁 / 신뢰를 증명하는 자. 대적자는 김서영 → 류은우 → 한서현. 남청색과 봉화의 금빛을 사용하는 전시 테마와 로컬 이미지 fallback 추가.
- 본선 후보 누적: 월간 아카이브에서 자동 집계한다. 수치를 별도 하드코딩하지 않는다. 기존 `student_get_records_mvp_finalist_top3()` 호출명·반환 구조를 유지하면서 TOP 4까지 반환하고 2023년 이준혁의 전시 이름만 구분한다.
- 공동 3위/4위 회랑을 각각 표시한다. 김승현 7회(1위), 김서영 6회(2위), 류은우·한서현 5회(공동 3위), 공예성·민서홍·이준혁(2023)·최민재 4회(공동 4위).
- 월간 개인 기여도: `student_get_records_guild_hall()`의 월간 개인 기여도 후보 정렬만 달성률에서 실제 점수로 수정. 공식 마감 원본의 이태우 / 2026-10 / 779.5점이 반환됨. 점수를 표시하면서 서로 다른 만점의 달성률로 1위를 고르던 불일치 해소. 시즌 기록과 다른 길드 전시는 유지.
- 구형 ‘현재 시즌 참고 기록’ 영역, 그 영역 전용 보조 함수·props·랭킹/통계 조회와 화면 진입 차단 로딩을 제거. ‘공식 확정 원장 참고’는 유지.

## 운영 데이터 보존

10월 MVP 한 건을 추가했다. 기존 월간 후보 배열, 과거 수상자 identity, 길드 마감 snapshot, 거래/점수 원장은 재작성하지 않았다. 수동 등록으로 밀려 있던 월간 아카이브 identity sequence를 감지할 때 앞으로만 정렬하는 보호 절차를 포함한다. 첫 적용 시 기존 id와 겹쳐 전체 롤백되었고, 원인 확인과 보호 절차 추가 후 성공했다.

`supabase/APPLY_RECORDS_OCTOBER2026_MVP.sql`은 이미 적용된 내용의 재현용이다. 이 프로젝트에서는 다시 실행할 필요가 없다.

## 검증 완료

- 변경 TS/TSX 5개: TypeScript 5.6.3 `transpileModule` 구문 검사 및 `git diff --check` 통과. 패키지 설치/빌드는 하지 않음.
- 순수 JSX 실행 검사: 로그인 좌/우 분리, 7개 로컬 자산 존재, 10월 제목/수상자/대적자 순서, 공동 4위 포함 8명 표시, 지휘관 779.5점 표시, 구형 영역 제거 확인. 실제 CSS/브라우저 렌더 E2E와 구별함.
- 3·4·5·7·10월 WebP 파일은 지정 CDN에서 다운로드 후 이미지 디코딩 확인.
- 운영 아카이브와 실제 RPC 본문 SELECT의 결과로 횟수·순위·기여도 검증.
- 기존 두 RPC의 정확한 signature, SECURITY DEFINER, 고정 search_path, authenticated 전용 EXECUTE ACL 유지. 비로그인 호출은 P0930으로 거부됨.
- 보안 advisor의 변경 전후 항목·개수 동일. 기존 광역 advisory는 이번 패치 범위 밖이며 신규 경고 증가 없음. [Supabase 보안 advisor 안내](https://supabase.com/docs/guides/database/database-linter).
