# 편린 능력치 관리 확장 — 2026-10-09

교사 운영패널 → 성장 시스템 → 편린 능력치에서 공명력·치명타율과 함께 주/부 속성, 배분값, 원정 특기를 설정한다.

- 속성 총합: 기존 DB 규칙 8/9/10 중 선택. 주 속성 1~10, 부 속성 0~10, 합계 일치.
- 부 속성 없음: 0점. 주·부 속성 중복 불가.
- 원정 특기: 유적(RUINS), 자연(NATURE), 성소(SANCTUARY).
- 미설정 신규 편린도 프로필 생성 가능. 미설정 항목을 그대로 둔 공명력·치명타율 단독 변경도 가능.
- 변경된 프로필만 전송. 기존 원정 profile_status/version/복원 비용/metadata는 보존.
- 새 원정 프로필은 기존 테이블 기본값 ACTIVE/version을 사용하고 복원 비용은 NULL(복원 대상 제외)로 유지한다. 이 화면은 복원 비용 설정 화면이 아니다.
- 교사 역할 검증 및 행 잠금 후 기존 능력치 RPC와 프로필 upsert를 한 트랜잭션으로 실행. 실패 시 전체 취소.
- 기존 RPC 시그니처를 변경하지 않고 별도 JSONB RPC 2개를 추가해 이전 화면과 호환한다.
- 원정 주간/참가 기록 등 기존 스냅샷에 소급 적용하지 않는다.
- 저장 중 입력/버튼 비활성화, 카드 내부 오류, 성공 toast, 속성/특기/원정/컬렉션 캐시 갱신.

운영 DB migration: `20261008155719_character_combat_profile_admin.sql` 적용 완료. 기존 편린 값 변경 없음. 네빌 값은 자동 지정하지 않음.

검증: SQL Editor-safe 구조/제약 검사 25건(ROLLBACK), migration 전후 능력치 및 전체 프로필 동일 확인, TS/TSX 구문 검사. 실제 교사 JWT RPC 및 브라우저 E2E/production build는 미실행.

사용자 확인 순서:
1. 통합 ZIP의 APPLY_PATCH.cmd 실행. 이전 영입 조건 패치 적용 여부 자동 감지.
2. 로컬 `npm run build` 후 기존 배포 절차 진행. AI는 npm 설치/빌드/커밋/푸시 실행 금지 규칙 유지.
3. 교사 로그인 후 네빌 검색. 속성 총합 10, 바람 7·어둠 3, 성소를 예시로 입력해 저장/새로고침 확인(권장값이며 자동 설정하지 않음).
4. 공명력만 변경하는 기존 편린, 단일 속성(부 속성 없음/0), 중복 속성/합계 오류, 되돌리기 확인.
5. 학생 편린 도감/원정 선택에서 반영 확인. 이미 확정된 원정 기록은 보존 확인.
