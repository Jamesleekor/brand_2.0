# 편린 원정 적합도 — 상성 계산 수정 (2026-10-17)

탐사지와 같은 속성의 점수를 합산하던 구현 오류를 수정했다.
현재 원정 미리보기와 실제 제출은 같은 서버 함수
`_expedition_compute_fit_v1(bigint,text,bigint[])`를 사용한다.
함수 이름은 RPC 호환성을 유지하며, 주차·결과의 계산 버전으로 동작을 구분한다.

## 계산

| 탐사지 속성 | 점수에 반영되는 편린 속성 |
| --- | --- |
| 수 WATER | 지 EARTH |
| 화 FIRE | 수 WATER |
| 풍 WIND | 화 FIRE |
| 지 EARTH | 풍 WIND |
| 광 LIGHT | 암 DARK |
| 암 DARK | 광 LIGHT |

편린 3명의 주·부속성 점수 중 위의 유리한 속성을 모두 합산한다.
동속·중립·열세 속성은 해당 성분에 점수를 더하지 않으며 별도의 감점은 없다.

```text
주성분 = 70 × min(주속성에 유리한 속성 합 / 14, 1.2)
부성분 = 30 × min(부속성에 유리한 속성 합 / 8, 1.2)
특기 = min(일치 인원 × 5, 10)
적합도 = 반올림(주성분 + 부성분 + 특기), 최대 130
```

등급 경계와 흔적, 보상 확률은 변경하지 않았다.

## 버전과 이력

- 수정 버전: `ELEM_70_30_COUNTER_V2`.
- 기존 `ELEM_70_30_V1` 주차는 당시의 동속 계산을 유지한다.
- 신규 생성 주차는 V2를 사용하며, 공개 시 설정 스냅샷에도 같은 버전을 기록한다.
- 수정 시 진행 중인 실제 학급 주차의 제출은 0건이었다.
  제출 이력이 없는 DRAFT/PUBLISHED 주차만 V2로 전환했다.
- 이미 제출·정산된 원정, 보상과 편린 프로필 스냅샷은 수정하지 않았다.
- 내부 계산 함수는 학생·익명 계정이 직접 호출할 수 없다.

## 검증

- SQL: `tests/expedition_counter_fit_v2.sql`.
  실제 배포 함수 정의를 임시 테이블에 연결해 검증한 후 전부 롤백한다.
  상성 6종, 동속 제외, 토/일 환경, 부속성 합산, 70:30 계산,
  특기 상한, 최대 130, 과거 V1 보존 등 26개 검증을 통과했다.
- 클라이언트: `node --experimental-strip-types tests/expedition_counter_fit_v2.mjs`
  (Node 22.6 이상). 상성 6종과 SQL 결과 일치를 확인했다.
- 은하수 관측소(주 수/부 화), 같은 편성 전후:
  고양이 마스코트·여우 탐정·네리아: 35 → 110.
  루미·아르테미아·카일: 84 → 36.
- production npm 설치·빌드는 저장소 운영 규칙에 따라 실행하지 않았다.
  사용자 로컬 빌드와 실제 로그인 브라우저의 안내 표시 확인은 별도다.
