- 큰 통계 카드 대신 한 줄 요약과 프로그램 관리 / 요청 검토 / 처리 이력의 세 탭.
- 프로그램 요약은 데스크톱 2열. 카드 전체를 클릭하면 아래 공통 상세에 반영.
- 상세는 기본 정보 / 멘토·관리 기능의 2열. 640px 미만에서 1열 전환.
- 진행·시작 준비 프로그램을 기본 표시. 종료·취소 프로그램 포함 선택 지원.
- 요청 검토에는 PENDING만 표시. 처리 이력은 서버가 반환한 나머지 상태를 모두 보존.
- 이력 학생·상태 필터 및 12건 단위 페이지 이동. 검증 원본·메모·멘토 도움·승인 회수는 펼쳐 확인.
- 등록·초안 수정·활성화·연장·취소·검토·승인 회수·최종 정산의 RPC/조건은 유지.

## HALL 07 아케이드의 지배자

- 범용 전시관 렌더러에서 전용 아케이드 전시 컴포넌트로 분기.
- 게임별 최고 점수 전광판을 데스크톱 2열로 배치. 동점자는 모두 공동 전시.
- 다승·서로 다른 게임 우승·그랜드 슬래머·최장 왕좌 등 모든 나머지 부문도 2열 명예 카드로 보존.
- 사이언·핑크 네온 간판, 어두운 전광판, 작은 조작 버튼 장식. 반복 애니메이션/외부 이미지 추가 없음.
- 720px 미만에서 1열, 400px 미만에서 이름/수치도 세로 정렬해 긴 점수·이름 대응.
- FINALIZED 안내 → 공인기록. Focus + Reaction + Combo → 집중 반응. Pure Reaction Speed → 순수 반응 속도.
- 게임 식별자 우선으로 한국어 이름 표시. 이력 제목/부제의 영문 게임명도 표시 단계에서 치환.
- 원본 스냅샷, 게임 점수/단위, 집계 조건, 학급 범위, RPC와 DB는 변경하지 않음.

## 적용 및 확인

원클릭 패치는 지정 프로젝트 경로에만 적용하고, 모든 파일을 사전 확인한 뒤 원본 백업을 만든다.
뉴비 페이지 원본은 줄바꿈/BOM 차이를 허용한 해시 검사, 전당 분기는 고유 문맥 검사.
기존 커스텀 변경이 충돌하면 덮어쓰지 않고 중단한다. 재실행은 적용 완료로 처리한다.

AI는 AGENTS.md에 따라 npm 설치/production build를 실행하지 않는다.
TypeScript 구문 검사 및 패치 적용·재실행·충돌·복구 검증을 수행하며 실제 운영 세션 확인은 별도다.

사용자 PC에서 `npm run build` 후 아래를 확인한다.

1. 두 학생 카드가 2열로 보이고 선택 시 상세 학생/멘토가 함께 바뀌는지.
2. 취소 프로그램이 기본 목록에서 빠지고 종료 포함/처리 이력에서 확인되는지.
3. 검토 대기 0건일 때 승인 기록이 검토 탭에 나타나지 않는지.
4. 처리 이력 필터·페이지 이동·근거 펼치기·승인 회수 버튼 접근이 가능한지.
5. 초안 수정·활성화 검토·연장·취소·최종 정산 버튼의 기존 노출 조건이 유지되는지.
6. HALL 07이 전용 네온 전시관으로 보이고 두 게임의 이름이 정확히 한국어로 표시되는지.
7. 공동 기록 보유자와 모든 명예 부문이 누락 없이 보이는지.
8. 빈 기록 상태·긴 이름·작은 화면에서도 가로 넘침 없이 읽을 수 있는지.
