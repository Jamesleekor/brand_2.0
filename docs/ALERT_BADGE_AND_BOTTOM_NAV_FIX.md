# 알림 읽음 및 하단 내비게이션 수정

소식함 알림의 개별/모두 읽음 성공 시 해당 학생·학급의 알림 목록과 홈 캐시를 함께 갱신한다. 진행 중 조회를 취소한 뒤 읽음 상태와 미확인 개수를 반영하고 두 조회를 무효화하여 서버 상태와 재동기화한다. 소식함의 알림 Realtime 콜백도 홈 캐시를 무효화한다. 실패 시 읽음 수를 변경하지 않는다.

AppShell 본문은 하단 공간을 CSS 변수로 확보한다. BottomNav가 실제 높이와 bottom 위치를 측정하고 16px 여유를 더한다. ResizeObserver 및 resize에서 재측정하며, 하단 위치는 16px와 기기 안전 영역 중 큰 값이다. 내비게이션이 없는 페이지에는 기존과 같이 별도 공간을 적용하지 않는다.

검증: Node 내장 TypeScript 변환으로 실제 캐시 갱신 함수와 레이아웃 effect를 추출해 개별/모두/중복 읽음, 홈 캐시 없음, 학생 범위 무효화, 안전 영역, 높이 변경, 화면 회전, cleanup을 모의 검증했다. npm 설치/빌드는 실행하지 않았다. 실제 모바일 브라우저 검증은 미실시.

배포 후 확인: 알림 1개 읽고 홈 복귀 시 개수 감소; 모두 읽고 복귀 시 배지 제거; 새 알림 도착 시 증가; 모바일 홈과 긴 페이지의 마지막 버튼을 스크롤하여 누를 수 있는지 확인; 세로/가로 및 홈 인디케이터가 있는 기기 확인.
