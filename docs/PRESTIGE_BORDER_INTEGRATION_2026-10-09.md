# 명품관 명예 테두리 연결 (2026-10-09)

## 범위

- 홈 → 편린 → 원정 연대기 최하단 명품관: 세 시안의 친구창·길드·BV 랭킹 미리보기, 판매 상품 조회·기존 구매 RPC, 보유 명예 테두리 장착·해제.
- 홈 → 친구, 길드원 목록, BV를 포함한 공통 랭킹 카드, 레이드 관문 로비 이름표, 교사 레이드 중계 참여자 카드: 장착 테두리 표시.
- 레이드 전투 화면에는 학생 목록 카드가 없어 별도 표시 지점이 없다. 중계 화면은 교사용 `RaidBroadcastPage`다.
- 화폐/전투력/BV 변경 없음. DB schema migration 없음.

## 상품 등록 계약

1. `cosmetic_items.category`는 정확히 `prestige_border`로 등록한다. `item_uid`는 moon/tree/dragon 등 디자인을 식별할 수 있게 정하고, `resource_url`에는 **중앙과 글자가 없는 투명 테두리 자산**을 사용한다. 구매 종료 후에도 장착할 수 있도록 보유 아이템의 `is_active`를 유지한다.
2. `expedition_luxury_catalog`에 같은 아이템을 `luxury_group='B'`, `required_effect_level=2`, `presentation_kind='PRESTIGE_BORDER_IMAGE'`, `is_active=true`로 연결한다.
3. `cosmetic_item_pricings`에 실제 확정 가격을 등록한다. `seasonal_items`에 판매 기간을 등록한다.
4. 학급에 명품관 개방 월드효과 `COSMETIC` Lv2 이상이 활성화되고 판매 기간 안에 있어야 구매 목록에 보인다. 구매한 권리는 개방 효과와 판매 기간이 끝나도 유지된다.

공통 표시 컴포넌트는 같은 학급의 장착 내역을 화면당 한 요청으로 조회하고 30초 캐시하며, 열린 화면에서는 45초마다 갱신한다. 기존 RLS에 따라 다른 학급의 소유권은 응답되지 않는다. 교사는 중계 화면에서 학생의 장착 상태를 읽을 수 있다. 장착 RPC는 본인 소유와 카테고리, 학급을 서버에서 검증한다.

테두리 이미지는 카드 너비·높이가 다르므로 **모서리 중심의 9분할 자산**으로 제작한다. 중앙에 텍스트·티어 아이콘·불투명 배경을 넣지 않는다. 공통 컴포넌트가 테두리 이미지를 `border-image-slice: 20%`로 늘리고, 좁은 레이드 이름표에는 6px 폭을 쓴다. 상품 미리보기의 샘플 카드도 같은 자산을 사용한다. 기존 생성 이미지처럼 이름·배경이 한 장에 합쳐진 목업은 판매 자산으로 등록하지 않는다.

## 적용 및 검증 순서

1. 프론트엔드 소스 패치를 적용한 뒤 사용자 로컬 PC에서 `npm run build`를 실행한다.
2. 투명 자산 URL을 열어 배경과 이름이 없는지 확인하고, 그 후 상품·가격·기간·카탈로그를 등록한다. 운영 DB는 현재 0건이므로 등록 전에는 판매 카드가 보이지 않는다.
3. 테스트 학생이 Lv2 개방 중 상품을 구매한다. 명품관의 “내 명예 테두리”에서 장착하고 친구·길드·랭킹·로비·중계 화면에 나타나는지 확인한다.
4. 같은 학생이 해제하면 모든 화면이 기본 카드로 돌아가는지 확인한다. 판매 기간 종료 후에도 보유·장착·해제가 가능한지 확인한다.
5. 다른 학생의 상품을 장착할 수 없는지, 다른 학급의 장착 정보가 조회되지 않는지, 24인 레이드 중계의 참여자 카드가 읽히는지 확인한다.

현재는 실제 테두리 상품/소유자가 없어 로그인 구매·장착 E2E를 실행하지 못했다. 이 변경은 리포지토리 커밋·배포 전 소스 단계다.

## 2026-10-10 첫 개방

- 운영 DB에 명예 테두리 3종(월광의 유리·세계수의 서약·황금룡의 맹세)을 등록했다. 각 300 GOLD, 구매 가능 기간은 2026-10-10 00:00부터 2026-11-10 00:00 직전까지(한국 시간)다.
- 운영 DB의 `student_get_expedition_luxury_shop`과 `student_purchase_cosmetic`은 이 3종의 `metadata.trial_open`과 `trial_until`을 확인한다. 그 기간에는 COSMETIC 월드효과가 없는 학급도 해당 상품만 구매할 수 있다. 다른 명품관 상품의 월드효과 조건은 그대로 적용된다.
- 상품 SVG는 DB `resource_url`에 data URI로 저장되므로 별도 CDN 배포 없이 표시된다. 같은 자산 원본은 `public/prestige-borders`에 보관한다. 중앙에 글자·배경이 없는 9분할 테두리다.
- 기간이 끝나도 이미 산 상품은 `cosmetic_items.is_active`를 유지하므로 장착·해제할 수 있다. 운영 DB에 이 개방 SQL은 이미 적용됐으며, 저장소 기록본은 `supabase/APPLY_LUXURY_GALLERY_OPENING_20261010.sql`이다. 중복 적용으로 학생 구매 기록을 수정하지 않는다.
- 읽기 검증: 학생 권한을 모사한 SQL 트랜잭션에서 `open=true`, `access_level=2`, 상품 3종을 확인했다. TEST 학급 학생의 구매→장착도 트랜잭션 안에서 성공했고 `ROLLBACK`으로 구매·차감·소유권은 남기지 않았다. 실제 로그인 UI와 로컬 빌드는 아직 사용자 검증이 필요하다.
